# 提示词：S4-H 产业逻辑抽取

> 用在扣子「大模型」节点，输出格式选 **JSON**，温度 **0.3**。
> 输入变量用 `{{变量名}}` 引用上游节点。

---

## 输入变量

| 变量 | 来源 | 示例 |
|---|---|---|
| `sector` | 循环变量 `item.sector` | 通信 |
| `stocks` | 循环变量 `item.stocks` | 中际旭创、新易盛、天孚通信 |
| `pct_avg` | 循环变量 `item.pct_avg` | 6.4 |
| `excess` | 循环变量 `item.excess` | 1.8 |
| `streak` | 循环变量 `item.streak` | 3 |
| `news` | 搜索节点输出（拼接成文本） | ... |

> 如果循环变量里没有 `pct_avg` / `excess`，从 `S3-F.scored` 对应条目里取，
> 或者直接删掉这两个占位，不影响判断。

---

## 提示词正文

```
你是A股产业研究员。任务：为板块「{{sector}}」构建产业链，并判断这波资金是产业驱动还是情绪驱动。

【已知】
板块名：{{sector}}
今日上榜个股：{{stocks}}
板块今日涨幅：{{pct_avg}}%，相对大盘超额：{{excess}} 个百分点
连续上榜天数：{{streak}}

【检索到的近期信息】
{{news}}

【输出要求】
只输出 JSON，不要解释，不要 markdown 代码块，不要多余文字：
{
  "driver": "政策|订单|涨价|技术|事件|纯资金",
  "catalyst": ["具体催化，每条一句话，带时间或主体"],
  "chain": {
    "upstream": ["上游环节"],
    "midstream": ["中游环节"],
    "downstream": ["下游环节"]
  },
  "shovel": ["卖水人环节"],
  "prosperity": "上行|平稳|下行",
  "duration": "强|中|弱",
  "risk": ["风险点"],
  "confidence": 0-100,
  "one_liner": "一句话结论，不超过30字"
}

【硬约束】
1. 检索信息里没有实质增量时，driver 必须填"纯资金"，catalyst 必须是空数组。
   不要用板块知识去编造新闻。
2. "AI需求增长""国产替代空间大"这类长期叙事不算催化。催化必须有时间点或主体，
   例如"某部委9月发布XX规划""某公司公告10亿元扩产"。
3. shovel 只能是设备、材料、耗材、检测、关键零部件环节，不能填终端品牌或整机厂。
4. chain 里填通用环节名（如"光芯片""封装测试""光纤预制棒"），不要填公司名。
5. confidence 表示你对 driver 判断的把握，不是对板块的看好程度。
   信息不足时给 30-50，不要因为板块涨得好就给高分。
6. 所有字段必须有值。不确定时：driver 填"纯资金"，prosperity 填"平稳"，duration 填"弱"。
```

---

## 为什么这么设计

### ① 为什么要明确「编造新闻」是禁止的

大模型对产业很熟，你不限制，它会用训练数据里的旧事当"近期催化"，输出看起来
非常专业但完全无法验证。约束 1 就是逼它在没有证据时诚实地说"纯资金"。

### ② 为什么区分「叙事」和「催化」

"AI 需求爆发"是叙事，能讲三年；"某公司公告 10 亿扩产"是催化，只能讲一周。
前者不能作为买点依据——因为它在任何一个时点都成立，等于没有信息量。

### ③ 为什么 chain 里不许填公司名

产业链要的是"环节"，Step 6 才根据环节去找具体公司。
如果这里直接给公司名，等于跳过了筛选，而且模型给的公司名单质量很差。

### ④ 为什么 confidence 是「判断把握」而不是「看好程度」

这两者混淆是散户最常见的思维陷阱：一个板块越涨越觉得"逻辑很硬"。
把 confidence 定义成"我对 driver 分类有多大把握"，它就变成了一个校准指标——
低置信度的 A 类会被 S4-I 自动降级为 B 类。

## 参考输出（合格样例）

```json
{
  "driver": "订单",
  "catalyst": [
    "中航光电公告子公司光通讯业务翻倍增长，三季度净利同比+172%",
    "一博科技签约10亿元AI算力高端PCB项目"
  ],
  "chain": {
    "upstream": ["光芯片", "光纤预制棒", "高速铜缆"],
    "midstream": ["光模块封装", "光器件", "PCB"],
    "downstream": ["数据中心", "AI服务器", "电信运营商"]
  },
  "shovel": ["光芯片", "光模块封装设备", "高频PCB"],
  "prosperity": "上行",
  "duration": "中",
  "risk": ["海外算力资本开支不及预期", "光芯片产能释放导致价格下行"],
  "confidence": 65,
  "one_liner": "算力资本开支驱动，卖铲子在光芯片和封装设备"
}
```

## 参考输出（不合格，应重试）

```json
{
  "driver": "技术",
  "catalyst": ["AI快速发展带动光模块需求"],     ← 这是叙事不是催化
  "chain": {"upstream": ["中际旭创"]},          ← 填了公司名
  "shovel": ["光模块"],                         ← 光模块是产品不是卖水人环节
  "confidence": 95                               ← 没有证据却高置信
}
```

看到这三种情况，说明提示词没生效，检查变量是否传进去了、温度是否过高。
